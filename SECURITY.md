# Security status

ZSV is experimental research. Do not send funds to it or use its fixture keys. No Zcash mainnet or public-testnet activation exists. Passing model tests do not establish consensus compatibility, economic solvency, privacy or a dollar peg.

The model, native integration proposal, threat model and independent adversarial review are separate artifacts. Read `docs/threatmodel.md`, `docs/economic-review.md`, `docs/adversarial-review.md` and `docs/zebra-integration.md` before extending it.

Report reproducible model issues in this repository without secrets or real user data. A production security contact and coordinated disclosure policy must be established before any value-bearing deployment; none is implied by this research repository.
