# ZSV ZIP draft

The canonical working draft is [draft-ijaack-zsv.md](../zips/draft-ijaack-zsv.md), authored and owned by **Giacomo Barbieri <hey@jaack.me>**. Its intended category is **Consensus**. It has no assigned number and has not been submitted upstream.

The [readiness record](zip-readiness.md) describes the proposed rules, verification scope and remaining submission/deployment work. The whitepaper, prototype, economic studies and Zebra experiments support the ZIP. Public payments are the initial scope; shielding is follow-up work. Dev Fund allocation and reserve stabilization remain separate candidate work.

This file preserves links to the earlier requirements outline. The canonical draft contains the current proposed specification.
